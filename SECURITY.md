# Security

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/AH-Merii/neoblocks.nvim/security/advisories/new),
not in a public issue. Only the latest release is supported.

neoblocks runs inside Neovim with your permissions and has no dependencies; CI runs only the GitHub Actions pinned in
`.github/workflows/`, which Dependabot keeps up to date.
